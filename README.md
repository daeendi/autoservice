# AutoService (Сервис автосервиса)

Клиент-серверное приложение для управления автосервисом. Включает в себя управление пользователями (клиенты, менеджеры, администраторы), учет автомобилей клиентов, каталог услуг и систему бронирования заявок на ремонт.

## Структура проекта

### Пакет `model`
Содержит базовые сущности предметной области.
- `UserRole` — перечисление ролей пользователей (ADMIN, MANAGER, CUSTOMER).
- `User` — абстрактный класс пользователя.
- `AdminUser`, `ManagerUser`, `CustomerUser` — наследники `User` с уникальными полями.
- `Car` — автомобиль клиента.
- `CarServiceItem` — услуга автосервиса (название, цена, длительность).
- `Appointment` — заявка на обслуживание.

### Пакет `repository`
Хранилища данных в оперативной памяти (in-memory).
- `UserRepository`, `CarRepository`, `ServiceRepository` — используют `HashMap` для хранения объектов и быстрого поиска по ID.
- `AppointmentRepository` — использует `ConcurrentHashMap` (для потокобезопасности) и `ConcurrentLinkedQueue` для организации очереди новых заявок.

### Пакет `service`
Бизнес-логика приложения.
- `UserService` — регистрация (с проверкой на пустой и дублирующийся email).
- `CarService` — добавление авто (проверка VIN-кода на 17 символов и проверка, что владелец — клиент).
- `ServiceCatalogService` — управление каталогом услуг.
- `AppointmentService` — создание заявок (проверка даты, владельца авто и роли).
- `AppointmentWorker` — многопоточная обработка очереди заявок с использованием `ExecutorService`.
